# API Contract: Get Goods Receipt

**Endpoint**: `GET /api/goods-receipts/:id`

**Purpose**: Retrieve a complete Goods Receipt with full details, line items, and linked PO/PR context for viewing and posting.

---

## Request

### URL Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `id` | UUID | Yes | Unique identifier of the GR to retrieve |

### Headers

```
Content-Type: application/json
```

### Query Parameters

None

---

## Field Descriptions

### GR Header Fields

| Field | Type | Description |
|-------|------|-------------|
| `id` | UUID | Unique identifier of the GR |
| `grNumber` | String | Human-readable GR identifier (auto-generated by backend) |
| `status` | Enum | DRAFT (editable) or POSTED (finalized) |
| `receiptDate` | Date | Date goods were received |
| `notes` | String | Optional notes about receipt (damage, discrepancies, etc.) |
| `createdAt` | ISO 8601 | Timestamp when GR was created |
| `updatedAt` | ISO 8601 | Timestamp of last update (refreshed on status changes) |

### PO Reference

| Field | Type | Description |
|-------|------|-------------|
| `po.id` | UUID | PO unique identifier |
| `po.poNumber` | String | PO human-readable number (e.g., PO-2026-0001) |
| `po.vendorName` | String | Vendor name from PO header |

### GR Line Item Fields

| Field | Type | Description |
|-------|------|-------------|
| `lines[].id` | UUID | Unique identifier of GR line |
| `lines[].lineNo` | Integer | Line sequence within GR (1-based) |
| `lines[].poLineId` | UUID | Reference to PO line |
| `lines[].itemCode` | String | Item/SKU code |
| `lines[].itemName` | String | Item description |
| `lines[].qtyOrdered` | Decimal | Quantity ordered on PO line |
| `lines[].qtyReceived` | Decimal | Quantity received in this GR line |
| `lines[].uom` | String | Unit of measure (UNIT, CASE, BOX, etc.) |
| `lines[].actualSiteCode` | String | Physical location where goods received |

### PR Traceability

| Field | Type | Description |
|-------|------|-------------|
| `prNumbers` | Array | Comma-separated list of linked PR numbers (from pr_line_allocations); empty array if no PR links |

## Usage in Frontend

### For GR Detail Page (Read-Only View in POSTED Status)

- Display GR header: number, status, dates, vendor
- Display line items in table: item name, qty ordered, qty received, UOM, site code
- Show status badge: green for POSTED, default for DRAFT
- If POSTED: hide edit/delete buttons, show read-only line items
- If DRAFT: show "Post GR" button to allow state transition
- Show linked PO number as clickable link: navigate to PO Detail page
- Show linked PR numbers as clickable links: navigate to PR Detail pages

### For GR Create Page (Selection of PO Lines)

This endpoint is NOT called during creation; it's called for viewing after creation.

---

## Workflow

1. Frontend calls `GET /api/goods-receipts/:id`
2. Backend:
   - Validates ID format (UUID)
   - Queries goods_receipts by ID
   - If not found, return 404
   - If found, query:
     - gr_lines for this GR (with joined po_lines data)
     - pr_line_allocations + purchase_requisitions for PR traceability
   - Transform rows into response DTO
   - Return 200 with full GR object
3. Frontend renders GR detail page with form controls based on status:
   - DRAFT: Enable "Post GR" button, allow viewing line items
   - POSTED: Disable "Post GR" button, show read-only line items

---

## Status Codes

| Code | Meaning | When |
|------|---------|------|
| 200 | OK | GR successfully retrieved |
| 400 | Bad Request | Invalid ID format |
| 404 | Not Found | GR not found by ID |
| 500 | Server Error | Unexpected server-side error |

---

## Notes

- All line items in the response include both qtyOrdered (from PO) and qtyReceived (from GR) for transparency
- prNumbers field enables traceability back to original purchase requisitions
- If GR has no linked PR (e.g., PO created without PR requisition), prNumbers is empty array
- All timestamps are ISO 8601 format, UTC timezone
- Response does NOT include deleted or archived GRs; only active GRs are returned
